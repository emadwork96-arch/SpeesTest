# دليل إطلاق موقع فحص السرعة (النسخة 19)

هذه النسخة جاهزة للإطلاق الرسمي: خمس لغات، كل لغة برابط مستقل، صفحات قانونية، تحسين لمحركات البحث، أماكن إعلانات AdSense، وحماية للباقة. كل الإعدادات الشخصية (الاسم، الإيميل، الدومين، كود الإعلانات) تُكتب من **متغيرات البيئة** في Render دون تعديل أي ملف.

---

## أولاً: شكل المجلد (ارفعه كله إلى GitHub)

```
app.py                  الخادم والصفحات
content.py              نصوص الصفحات والمقالات بالخمس لغات (عدّل الكلمات من هنا)
gunicorn.conf.py
requirements.txt
render.yaml             اختياري
templates/  base.html  index.html  page.html
static/     style.css  app.js  theme.js  favicon.svg  og.png
```

**طريقة الرفع على GitHub بدون برامج:** افتح المستودع القديم، ثم **Add file ← Upload files**، اسحب كل محتويات المجلد (مع مجلدي `templates` و`static`) واضغط **Commit changes**. Render سيعيد النشر تلقائياً. إذا ظهر لك ملف `templates/index.html` القديم فسيُستبدل.

## ثانياً: ما الذي تغيّر

| الميزة | التفاصيل |
|---|---|
| روابط لكل لغة | `/ar` `/en` `/tr` `/fr` `/fa` ويُوجَّه الزائر من `/` إلى لغة متصفحه |
| محتوى للبحث | شرح للنتيجة وأسئلة شائعة بكل لغة (يحتاجه جوجل وAdSense) |
| صفحات قانونية | من نحن، الخصوصية، الشروط، اتصل بنا |
| SEO | عنوان ووصف وhreflang وcanonical وOpen Graph وبيانات منظّمة وsitemap.xml وrobots.txt |
| إعلانات | تُعرض فقط إذا كتبت `ADSENSE_CLIENT`، وتأتي **بعد** صندوق الفحص وليس حوله، وتُحمَّل بعد أن تهدأ الصفحة وليس أثناء القياس |
| حماية الباقة | حد لكل زائر في الساعة (6000 ميجابايت افتراضياً) حتى لا يستنزف أحد الباقة بسكربت |
| الخصوصية | لا خطوط خارجية ولا أي جهة خارجية سوى خدمات عنوان IP (وجوجل عند تفعيل الإعلانات) |

## ثالثاً: الخطوات بالترتيب

### 1) الدومين
اشترِ دومين قصيراً (حوالي 10-15 دولاراً في السنة) من Namecheap أو Cloudflare Registrar أو GoDaddy. يفضّل `.com`. AdSense لا يقبل عادةً العناوين المجانية مثل `onrender.com`.

### 2) الاستضافة (مهم جداً للتكلفة)
الفحص الواحد ينقل نحو 100-300 ميجابايت. راجع في موقع Render **صفحة الأسعار الحالية** لرسوم الباقة ورسوم زيادة الباندويث قبل أن تعلن عن الموقع.

- **الباقة المجانية في Render** تنام بعد فترة خمول (أول زائر ينتظر نحو دقيقة) وهذا يضر بالإعلانات والبحث. **لا تُطلق رسمياً عليها.**
- **الحل الأبسط:** ارفع الخدمة إلى باقة مدفوعة صغيرة (Starter، حوالي 7 دولارات شهرياً وقت كتابة هذا الدليل، تأكد من السعر) فلا تنام.
- **لو كبر الاستهلاك:** VPS بباقة بيانات كبيرة (مثل Hetzner) أرخص بكثير للحجم الكبير. وأستطيع لاحقاً تجهيز نسخة Docker أو نسخة Cloudflare Workers تولّد بيانات الفحص من أقرب مركز للزائر دون تحميل خادمك.

### 3) ربط الدومين بـ Render
1. في Render افتح الخدمة ← **Settings ← Custom Domains ← Add Custom Domain** واكتب `yourdomain.com` ثم `www.yourdomain.com`.
2. عند مسجّل الدومين (أو Cloudflare) أضف سجلات DNS التي يعرضها Render: عادةً `CNAME` لـ `www` نحو `xxxx.onrender.com` وسجل `A` أو `ALIAS` للدومين الرئيسي.
3. انتظر حتى تظهر علامة Verified. الشهادة (https) تُنشأ تلقائياً.
4. اختر النسخة الأساسية (مع www أو بدونها) وحوّل الأخرى إليها (Render يعرض خيار Redirect).

### 4) متغيرات البيئة
في Render: **Environment ← Add Environment Variable**:

| المتغير | مثال | ملاحظة |
|---|---|---|
| `SITE_NAME` | `SpeedCheck` | اسم الموقع في كل مكان |
| `SITE_URL` | `https://yourdomain.com` | **ضروري** للـ sitemap والروابط القانونية؛ بدون `/` في آخره |
| `CONTACT_EMAIL` | `hello@yourdomain.com` | يظهر في صفحة الاتصال والخصوصية؛ **لازم بريد حقيقي** |
| `OPERATOR_NAME` | `اسمك أو اسم شركتك` | اختياري، يظهر في «من نحن» (الافتراضي اسم الموقع) |
| `SERVER_LOCATION` | `Frankfurt, Germany` | اختياري، يظهر تحت الفحص؛ اكتب موقع الخادم الحقيقي في Render |
| `DEFAULT_LANG` | `ar` | اللغة عند عدم معرفة لغة الزائر (وللبحث) |
| `ADSENSE_CLIENT` | `ca-pub-1234567890123456` | **اتركه فارغاً حتى يقبلك AdSense** |
| `ADSENSE_SLOT_TOP` / `ADSENSE_SLOT_BOTTOM` | أرقام الوحدات | اختياري، إن أردت وحدات يدوية بدل الإعلانات التلقائية |
| `MAX_MB_PER_HOUR` | `6000` | حد كل زائر في الساعة؛ قلّله لو خشيت على الباقة |

بريد بدومينك: استخدم خدمة توجيه مجانية مثل Cloudflare Email Routing أو Zoho Mail.

### 5) مراجعة الصفحات القانونية
افتح `/ar/privacy` و`/ar/terms` وتأكد أن النصوص تناسب نشاطك. **هذه نصوص قياسية وليست استشارة قانونية.** بما أنك في تركيا يُستحسن أن يراجعها شخص مختص بشأن KVKK. وإن أردت تعديل كلمة فافتح `content.py`.

### 6) جوجل سيرش كونسول
1. ادخل إلى Google Search Console وأضف الدومين (طريقة Domain)، وضع سجل TXT الذي يعطيك إياه عند مسجّل الدومين.
2. من **Sitemaps** أضف `sitemap.xml`.
3. استخدم **URL Inspection** للصفحات `/ar` و`/en` واطلب الفهرسة.

### 7) التقديم على AdSense
1. أنشئ حساب AdSense وأضف دومينك.
2. اطلب كود الربط ثم انسخ رقم `ca-pub-...` فقط، وضعه في `ADSENSE_CLIENT` في Render. الموقع سيضيف تلقائياً وسم التحقق وملف `/ads.txt` وسكربت الإعلانات.
3. اضغط **Verify** في AdSense وانتظر المراجعة (من أيام إلى أسابيع).
4. **فعّل Privacy & messaging** من حساب AdSense ثم **GDPR** وأنشئ رسالة الموافقة. هذه خدمة جوجل المجانية المعتمدة وهي المطلوبة لزوار أوروبا وبريطانيا وسويسرا. لا تكتب شريط كوكيز بنفسك لأنه لن يكون معتمداً.
5. بعد القبول فعّل **Auto ads** من لوحة AdSense، أو أنشئ وحدتين وضع أرقامهما في `ADSENSE_SLOT_TOP` و`ADSENSE_SLOT_BOTTOM`.

**نصائح للقبول:** لا تقدّم قبل أن يكون الدومين حقيقياً والصفحات كلها تعمل. المحتوى الحالي (شرح وأسئلة) بداية جيدة، وزيادة 3-5 مقالات مفيدة لاحقاً (مثلاً «كيف أحسّن الواي فاي») ترفع فرص القبول والظهور في البحث. وتجنّب نقر إعلاناتك بنفسك نهائياً.

### 8) بعد الإطلاق
- راقب استهلاك الباندويث في لوحة Render أسبوعاً.
- شارك الموقع في مجموعات فريقك وعملائك، ولا تعتمد على البحث وحده في البداية.
- الربح في البداية قليل، وهو ينمو مع الزيارات من البحث على مدى أشهر.

## رابعاً: التجربة على جهازك
```
pip install -r requirements.txt
python app.py
```
ثم افتح `http://localhost:5000`. لتجربة الإعلانات محلياً: `ADSENSE_CLIENT=ca-pub-1234567890123456 python app.py`.

## خامساً: أين أعدّل؟
- نصوص الموقع والمقالات والصفحات القانونية: `content.py`
- نصوص واجهة الفحص (الأزرار، النتيجة، النسخ): قسم `I18N` أعلى `static/app.js`
- الألوان والمظهر: `static/style.css` (متغيرات الألوان في أعلاه)
- بعد أي تعديل على CSS أو JS غيّر `ASSET_VERSION` في Render إلى رقم جديد حتى يتحدّث التخزين المؤقت لدى الزوار.
